# QR Studio Pro - Generator QR Code Kustom & Instan

Aplikasi web modern untuk membuat dan mengkustomisasi kode QR secara instan dengan dukungan ekspor format **PNG Resolusi Tinggi (hingga 4096px)** dan **Vector SVG** murni tanpa pecah.

![QR Studio Pro](https://raw.githubusercontent.com/google/material-design-icons/master/png/action/qr_code_2/materialicons/48dp/2x/baseline_qr_code_2_black_48dp.png)

## Fitur Utama

- **Multitipe Konten**: URL Website, Teks, Wi-Fi, WhatsApp direct link, vCard kontak digital, dan Email.
- **Kustomisasi Bentuk & Pola**:
  - Pola titik: *Kotak, Bulat, Dots, Berlian, Fluid, Bintang*.
  - Bingkai mata sudut: *Kotak, Sudut Halus, Lingkaran, Daun Organik, Bevel Berlian*.
  - Titik pusat mata: *Kotak, Lingkaran, Membulat, Berlian, Bintang*.
- **Sematkan Logo / Brand**:
  - Unggah logo kustom (PNG, JPG, SVG, WebP).
  - Pilihan ikon brand populer instan (WhatsApp, Instagram, Web, YouTube, dll.).
  - Slider ukuran logo, padding, dan bentuk badge latar.
- **Warna & Gradien**:
  - Mode solid, gradien linear (dengan pengatur sudut derajat), dan gradien radial.
  - Latar belakang transparan atau custom color.
  - Warna bingkai dan pusat mata independen.
- **Ekspor Siap Cetak**:
  - Unduh PNG (512px, 1024px, 2048px, 4096px - 300 DPI siap cetak).
  - Unduh Vector SVG murni.
  - Salin gambar langsung ke clipboard atau salin markup SVG.
- **Responsif & Mobile-Friendly**:
  - Dioptimalkan untuk perangkat seluler dan desktop.
  - Mockup pratinjau: Kanvas, Layar Smartphone, Kartu Nama, dan Meja Kafe.

## Menjalankan Secara Lokal

1. Clone repositori:
   ```bash
   git clone <url-repo-anda>
   cd <nama-folder>
   ```

2. Pasang dependensi:
   ```bash
   npm install
   ```

3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```

4. Buka di browser: `http://localhost:3000`

## Build untuk Produksi

```bash
npm run build
```
